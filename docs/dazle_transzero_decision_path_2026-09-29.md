# DAZLE / TransZero：让属性进入最终分类决策

日期：2026-09-29。状态：机制研究、官方源码核对、本地数据准备度审计已完成；未启动训练、未评估新的模型准确率。

## 1. 结论与现有实验的关系

值得研究的具体改变是：用图像预测的属性兼容分数，与固定的类别属性档案直接生成类别分数。首轮不接回全图 CLIP 分类残差，否则无法单独判断该路径是否有效。建议先搭建 DAZLE 风格的密集属性注意力与读出，再把 TransZero 作为特征交互模块的增量对照。

这两者本身是属性零样本识别方法，不是原始 AG-CLIP 的模块。迁移到 CLIP / SigLIP 应称为 DAZLE-inspired / TransZero-inspired adaptation。

核对现有代码后的三个区别：

1. `multimodal/cub_tokens.py` 最后仍用“全图向量＋属性残差”与类别文字向量计算相似度。
2. `multimodal/cub_bottleneck.py` 只切断了辅助残差内部的视觉捷径；最终仍保留全图向量。它不等于整个分类器只通过属性决策。
3. 以前的 `diagnose_cub_class_attributes.py` 和 `diagnose_cub_mapped_attributes.py` 已尝试直接属性评分／融合，因此不能说我们完全没有检验过属性读出。它们使用冻结探针与后处理，没有联合学习“每个属性对应的密集视觉注意力＋属性读出”；其负结果必须保留。

## 2. 两种不能混淆的属性数据

设有 C 个物种、A 个属性：

- **属性词向量 V：A×d。** 每一行描述一个属性，例如“黑色头顶”。官方代码使用 GloVe 初始化；这是属性名称的语义表示。
- **类别属性档案 Z：C×A。** 每一行规定一个物种与各属性的关联强度。这是生成类别分数的固定依据，不是类别名称的 CLIP 向量。
- **图片属性标签 Y：N×A，可选。** 描述某张图的实际可见属性；与类别平均档案不同。遮挡、雌雄、季节、幼成体等都会导致差异。DAZLE 的核心分类损失不要求我们当前那套逐图 BCE 标签；TransZero 官方回归目标是类别档案，不是每张图片的可见属性标签。

最后一项可以在未来作为独立的辅助监督分支研究，不能声称原论文天然保证逐图属性正确。

## 3. DAZLE 的直接分类路径

令视觉主干产生 R 个空间位置的特征 F_r，属性 a 的词向量为 v_a。以下为默认线性读出的核心形式，省略可选偏置：

\[
\alpha_{ar}(x)=\operatorname{softmax}_{r}(v_a^\top W_2F_r),\qquad
h_a(x)=\sum_r\alpha_{ar}(x)F_r
\]

\[
q_a(x)=v_a^\top W_1h_a(x),\qquad
g_a(x)=\sigma(v_a^\top W_3h_a(x))
\]

\[
s_c(x)=\sum_a Z_{ca}\,g_a(x)q_a(x),\qquad
\hat y=\arg\max_c s_c(x)
\]

每个属性有自己的空间注意力；属性重要性 g 与属性证据 q 相乘，再进入固定 Z 读出。官方代码在初始化时按类别行归一化 Z，不能直接把原始 0–100 数值当作模型输入而忽略尺度。q 默认不是 sigmoid 概率，因此不能把其数值直接解释成“某属性存在概率”。

可核对的源码位置：`forward` 的 `A`、`F_p`、`S_p`、`A_p` 与 `S_pp`；`compute_loss` 默认由类别交叉熵和自校准项构成。虽然类中初始化了 BCE 损失对象，所检查的默认 `compute_loss` 并未调用它。

来源：[DAZLE 论文](https://hbdat.github.io/pubs/cvpr20_finegrainedZSL_final.pdf)、[官方固定版本源码](https://github.com/hbdat/cvpr20_DAZLE/blob/e5a04601d8368903008fd96dee3d95dde398aa51/core/DAZLE.py)。

## 4. TransZero 增加什么

保留“属性得分→固定 Z→类别分数”的核心，改变上游属性特征提取：

`空间特征 → 带相对几何处理的视觉编码器 → 以属性为查询的解码器 → 每个属性的视觉表示 → 属性得分 → Z 读出`

官方 `forward_feature_transformer` 输出 A 维语义嵌入；`forward_attribute` 与固定类别属性矩阵相乘。其目标包含类别交叉熵、类别属性回归 MSE、自校准损失。属性得分不是必须位于 [0,1] 的逐图概率。

官方 CUB 配置为冻结 ResNet-101 空间特征，448 分辨率、14×14 个区域、2048 维视觉特征、300 维 GloVe 属性表示，1 层编码器、1 层解码器、1 个注意力头。几何模块源码写有 `grid_size=(14,14)`，换图像尺寸或 CLIP B/32 时必须显式修改，不可随意把现有 3 个视图向量传入。

源码入口：[模型](https://github.com/shiming-chen/TransZero/blob/7c10cdbe76d36ec209b59127a6b1bb02fbd93852/model.py)、[CUB 配置](https://github.com/shiming-chen/TransZero/blob/7c10cdbe76d36ec209b59127a6b1bb02fbd93852/wandb_config/cub_gzsl.yaml)、[论文](https://arxiv.org/pdf/2112.01683)。

## 5. 损失与实验协议中必须分开的因素

两份官方源码的自校准函数均计算已见训练图片分配给未见候选类的总概率，再对批次均值取负对数：

\[
L_{cal}=-\log\left[\frac1B\sum_i\sum_{c\in U}p(c\mid x_i)\right].
\]

这不是使用未见图片训练，但会使用未见类别的语义档案和候选集合。它也不等于对每张图片分别取负对数后求均值。复现应记录实际公式、候选集合、偏置和 CE 分母，而非只复用损失名字。

官方两套构造器中 `is_conservative` 默认值不同，CE 可以在不同候选集合上计算。TransZero 固定版本训练入口使用 Adam，而论文描述 SGD；它还会定期调用评价函数并打印最佳值。借用代码时必须保留我们自己的开发集选择和最终评估隔离，不照抄训练脚本的全部流程，不凭此差异断言原作者的完整实验做法。

首个机制实验建议先关闭自校准，用统一 CE 候选约定检验属性读出；然后给所有可比变体添加完全相同的校准预算。这样能区分注意力、属性语义和已见／未见偏置调整的贡献。若改用此方案，即为有明确协议差异的改编，不称为完整复现。

## 6. 本地数据与特征审计

详见 [readiness.json](../reports/dazle_transzero_review_v1/readiness.json)。

| 项目 | 实际检查结果 | 对实施的含义 |
|---|---|---|
| CUB 类别属性表 | `data/cub/CUB_200_2011/attributes/class_attribute_labels_continuous.txt`，200×312，有限数值，范围 0–100 | 已有候选类别语义资源，无需用户另拍照片 |
| 当前 100 类映射 | 通过 manifest 的 source_id 对应到 100×312；完整向量没有完全重复的行 | 可构造固定 Z；无重复不等于属性可从图像可靠识别 |
| 原训练集支持的属性 | 230 个，对应 100×230 子表 | 可做继承现有词表的改编；不能称作原论文完整 312 属性实验 |
| 已有开发缓存 | `native_views` 为 1000×3×512 | 是全图＋两个裁剪的汇总特征，不是密集 patch / CNN 空间网格 |
| xlsa17 | `data/` 内未找到 `att_splits.mat` | 原协议复现需补充官方划分、语义文件并核对属性顺序与归一化 |

类别属性表是额外的基准语义信息。形状审计没有查明其上游汇总是否包含某些测试照片，因此不能把它描述成完全独立于未见图片标注的自然语言资料。若采用传统属性 ZSL 的固定基准语义，应明确允许这种信息，并与以前仅使用类别文字／公开描述的设定分表报告。不从最终评估图片重新计算、挑选或修改档案。

如要严格保持“未见物种不提供任何图片来源属性统计”的设定，应沿用独立公开描述构造 Z，并标记未知项；缺失不能当作属性不存在。此时需重新定义带缺失信息的读出，不能称为原版 DAZLE / TransZero 协议。

## 7. 建议的实现次序

以下为设计方案，尚未实现或训练。

### 第一步：建立纯属性读出

使用固定 Z，训练从视觉特征到 A 维属性得分的映射。最终只允许 `scores = attributes @ Z.T`，不加全图 CLIP 分类分支，不设置独立可学习的逐类别输出头。先验证索引、归一化和决策路径。

### 第二步：添加 DAZLE 式空间注意力

为了先隔离结构作用，建议固定同一视觉主干和相同 Z，比以下变体：

- 全局平均池化→属性读出；
- 密集空间特征＋均匀注意力→属性读出；
- 密集空间特征＋可学习属性注意力→属性读出；
- 上一项再增加属性重要性门控。

可先用冻结 ResNet-101 与原始 GloVe 建立接近官方的参照，再将同一读出移到 CLIP B/16。若优先与现有模型衔接，也可先做 CLIP 版本，但必须标明视觉和属性编码器变更；不得把普通 ViT patch 向量默认视为已校准的区域文本嵌入。当前 8 GB 本机宜缓存特征、从小批次开始，是否容纳完整配置需实测，本轮未验证资源峰值。

### 第三步：添加 TransZero 式交互

固定视觉主干、Z、词向量来源、训练图片、选择预算；加入轻量编码器／属性查询解码器。分别消融普通交叉注意力、相对几何处理、属性回归和校准。不把增加全部组件后的总收益归给单一属性机制。

### 第四步：独立检验语义利用

- 保持训练与测试一致地同时置换属性得分列和 Z 列，结果应不变。这是坐标重命名，不是负对照。
- 只打乱得分与 Z 的对应，用作推理时的依赖性干预；分数变化表明读出依赖对应关系，不单独证明泛化更好。
- 同容量模型在固定随机语义对应下重新训练，用作语义结构对照；模型可能学习任意编码，不能期待这种对照必然失效。
- 用独立可见属性标注评价属性预测，用部位／遮挡实验检验图像证据。注意力热图或属性通道本身不保证人类语义正确。

类别评分可按属性分解为 `contribution[c,a]=Z[c,a]*evidence[a]`。它是模型内部的代数贡献，不能直接称为现实世界的因果解释。

### 第五步：分类评价与成功标准

先在开发数据验证机制，再按锁定方案做多种子和类别划分复测。已有最终测试集被反复查看，新结果应标为探索性；确认性结论需要未用于选择的独立评估。至少报告 ZSL 宏平均准确率、GZSL 的 S/U/H 和配对差值；训练标签仅来自已见类。

允许未见候选类语义参与自校准时，事先明确哪些类别可见；不要训练中混入开发未见类图片，也不要根据最终类别成绩调整校准。单独报告“关闭校准”和“统一校准”结果。

成功有三个层次，不能混为一谈：

1. 属性是必经路径：结构／干预验证。
2. 属性具有真实语义：独立属性、部位与可靠性评价。
3. 属性带来额外分类收益：超过同主干、同语义资源、同训练预算的合理对照，并在重复实验中稳定。

原始 CLIP / SigLIP 仍应保留为系统基线。纯属性方案即便比属性平均池化好，也可能不如强大的原始视觉语言模型；这两种结论应同时报告。

## 8. 一个仅说明公式的例子

假设两个物种的档案分别为 `[1,0,1]`、`[0,1,1]`，每行除以 √2。图片预测的三个属性分数如下：

| 情况 | 属性分数 | 物种 A 分数 | 物种 B 分数 |
|---|---|---:|---:|
| 第一种证据 | [0.8,0.2,0.6] | 0.990 | 0.566 |
| 交换前两个属性 | [0.2,0.8,0.6] | 0.566 | 0.990 |
| 去掉两项判别属性 | [0,0,0.6] | 0.424 | 0.424 |

这是数值示意，不是模型测试成绩。它显示固定属性读出如何改变类别决策，也说明两类共有属性不足以区分它们。
