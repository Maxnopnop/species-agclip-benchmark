# 属性定位修复与明确属性决策路径

日期：2026-09-29。此版本承接四路线研究，以独立目录保存实验，不改写既有 SigLIP 2 基线或早期结果。

## 问题与设计

第一步检验：FG-CLIP 2 的冻结局部特征中是否已有可分辨的部位信息，只是默认文字查询没有正确读出？第二步检验：修复部位读出后，是否改善图片属性识别及明确通过属性进行的物种分类？

SigLIP 2 保留为独立的全图识别基线。本轮没有将其分数融合到属性分支，避免强全图分支掩盖属性是否有效。

## 固定数据与额外监督

- 使用既有 100 物种划分：500 张 `train_seen` 训练图、500 张开发图（已见与开发未见各 250 张）。
- 训练部位查询只使用这 500 张训练图的 CUB 可见部位关键点；开发图标注只评价。没有将最终评估照片或其属性目标用于训练、选择或评分。
- 使用训练集支持的 230 个属性、既有高置信可见属性标签，以及官方候选类属性档案。
- 官方类别属性档案属于传统属性 ZSL 的额外语义资源；不能把有此资源的分支与仅使用类别名称的原始 SigLIP 2 的差异全部归于架构。该档案的上游汇总来源也未证明完全排除测试图片。
- 基础模型预训练与 CUB 是否重叠仍未排除；本轮为反复使用开发数据后的探索实验。

## 定位分支

冻结 FG-CLIP 2 Base，使用 256 patch 的官方密集局部特征。训练四个归一化查询向量，对应头、翅膀、胸、尾。图像特征与查询的相似度经过空间 softmax；训练目标是可见部位关键点附近的高斯分布，宽度为图像对角线的 0.05。不可见部位不计入定位损失。

比较原始文字查询、由训练图统计的固定空间先验，以及三随机种子的可学习视觉查询。空间先验不看图像内容，可诊断 CUB 构图偏置。所有变体在相同 500 张开发图评价；命中半径固定为对角线的 0.1，不能与此前 75 张小样本的数字直接混为一组。

该分支采用已有人工关键点监督，是对局部可学习性的诊断，**不是 DEAL 原论文的无部位标注训练复现**。

## 属性决策分支

根据固定的部位对应关系，对每个属性取相应部位池化特征；未覆盖的背、腹、腿、整体形状等属性使用全图特征。设每个属性的预测证据为 `q_a(x)`，固定类别属性档案行归一化后为 `Z_c`，最终类别分数为：

`s_c(x) = 20 × normalize(q(x)) · Z_c`

没有额外的可学习逐类别输出头、类别偏置或视觉残差旁路。属性证据同时接受可见属性 BCE 和已见类 CE 训练；BCE 正例权重仅由训练标签计算，截断在 1–20。属性得分不应直接视为已校准概率。

这借用了 DAZLE/TransZero 的明确属性兼容评分思想；本轮不是完整 DAZLE、TransZero，也未加入 TransZero 的相对几何编码器或完整属性查询 Transformer。

读出层采用同容量、同训练预算，比较六种输入。`learned_part` 和 `wrong_part` 共享相应种子的额外 300 步部位查询训练结果；其他输入不进行这一阶段，因此相对 global/native 的差异还包含额外关键点监督与定位训练，不能全部解释为等总预算的架构收益。

| 变体 | 属性读出使用的图像信息 |
|---|---|
| global | 所有属性都使用 FG-CLIP 2 全图特征 |
| uniform | 局部属性使用密集特征的均匀平均 |
| native_part | 局部属性使用原始部位文字查询池化 |
| position_prior | 局部属性使用训练图统计的固定空间先验池化 |
| learned_part | 局部属性使用训练得到的正确部位查询池化 |
| wrong_part | 循环交换 learned_part 的四个部位后，重新训练属性读出 |

种子 42/43/44；定位 300 步，读出 400 步。固定使用最后一步，无开发集选择最佳检查点、无校准搜索、无原始 SigLIP 分数混合。

## 成功标准与验证

1. 定位层面：正确查询在未见开发类别上胜过原始查询和固定位置先验；同时检查部位间混淆。
2. 语义层面：图片属性 mAP 提升，特别是部位相关属性及未见类别；定位提升不自动等于属性识别提升。
3. 分类层面：正确定位的属性分支优于同预算全局、均匀和错误部位对照；仍需单独比较强 SigLIP 2 基线。
4. 结构验证：填充 patch 不影响定位；开发关键点不影响训练空间先验；清零全部属性证据后所有类别分数相同；同时重命名得分和档案列不改变预测。

仅打乱得分与档案一侧的对应是依赖性干预，不是独立泛化证明。三种子共享相同类别／图片，因此它们也不代表三套独立数据集。

## 运行

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest -v test_attribute_path
.\.venv\Scripts\python.exe -X utf8 attribute_path_experiment.py --stage all
.\.venv\Scripts\python.exe -X utf8 analyze_attribute_path.py
.\.venv\Scripts\python.exe -X utf8 export_attribute_path.py
.\.venv\Scripts\python.exe -X utf8 predict_attribute_path.py --image E:\path\bird.jpg --with-siglip
```

特征缓存：`cache/attribute_path_v1/`；检查点：`runs/attribute_path_v1/`；报告：`reports/attribute_path_v1/`。特征、权重、照片不上传 Git。已完成单元可复用，源码或配置变化会触发来源不一致检查。

单图入口仅接受图片和固定推理资源，不加载训练照片、逐图属性或关键点。默认比较 75 个开发候选物种；`--candidates all100` 可在全部预定义 100 类中评分，但该设置不是本轮报告的评价协议。种子默认 42，未按开发成绩挑选。属性分支属于研究模型，当前整体识别能力仍低于原始 SigLIP 2。
